# Phase 2F Travel Acceptance Checklist

Use this as a quick completion checklist after implementing Travel.

- [ ] Existing `nyxie-data` without Travel still loads.
- [ ] `travel.activeId`, `travel.trips[]`, and `travel.packingTemplates[]` persist.
- [ ] More → Travel works without adding a new bottom-nav tab.
- [ ] Multiple trips can be created and edited.
- [ ] Flight information is visually prominent in trip detail.
- [ ] Multiple flights sort chronologically.
- [ ] Stays persist.
- [ ] Ground transport entries persist.
- [ ] Itinerary supports timed and untimed items.
- [ ] Itinerary is a vertical mobile list, not a desktop table.
- [ ] Reusable packing templates persist.
- [ ] Template items can be copied/added into trip packing.
- [ ] Trip packing checkboxes persist.
- [ ] Budget estimate persists without touching Money.
- [ ] Confirmation/reference items persist and wrap on narrow screens.
- [ ] Food spots are manual only and persist.
- [ ] Post-trip reset checklist persists.
- [ ] Linked Convention resolves by ID rather than copied data.
- [ ] No Convention/Cosplay source-of-truth data is duplicated unnecessarily.
- [ ] No Travel action creates a Money transaction automatically.
- [ ] 360px layout has no horizontal overflow.
- [ ] No green/orange accents were introduced.
- [ ] Existing Home, Plan, Money, Cosplay, and Convention visuals were not redesigned.
