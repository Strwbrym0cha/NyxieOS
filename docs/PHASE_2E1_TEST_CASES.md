# Phase 2E.1 Manual Test Cases

1. No conventions
   - Home shows safe empty Coming Up fallback.

2. One future convention
   - Home shows its name and countdown/date.

3. Two future conventions
   - Home shows the earlier start date.

4. Edit later convention to an earlier date
   - Home switches to that convention.

5. Mark nearest convention Completed
   - Home switches to the next eligible convention or fallback.

6. Convention starts today
   - Home treats it as eligible and shows Today/date context.
