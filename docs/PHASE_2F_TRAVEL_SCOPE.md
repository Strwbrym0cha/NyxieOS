# Phase 2F Travel Scope Guardrails

Phase 2F is Travel only.

Allowed:
- persisted Travel data
- More → Travel navigation
- trip list/create/edit/detail
- flights
- stays
- lightweight ground transport
- itinerary
- packing templates
- trip packing
- manual confirmations
- manual food spots
- post-trip reset
- convention link by ID
- minimal compatibility wiring required for More navigation

Not allowed in this phase:
- Home redesign
- Plan redesign
- Money redesign
- Cosplay redesign
- Convention redesign
- Creator HQ
- Wellness
- Routines
- Yuu-Kun redesign
- airline APIs
- live flight tracking
- maps
- weather API
- reservations/booking
- push notifications
- automatic Money transactions
- AI travel recommendations
- social/relationship tracking

If a requested implementation detail would require one of the excluded systems, leave a clean placeholder/data field rather than expanding scope.
