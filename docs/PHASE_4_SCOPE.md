# Phase 4 Scope Guardrails

This is a finish-the-app pass, not a new-feature phase.

Allowed:
- correctness fixes from final integration review
- missing lightweight fields/behaviors already promised in Phase 3
- local-rule improvements for Yuu-Kun
- GitHub Actions build verification
- optional GitHub Pages deployment
- tiny refactors needed for maintainability and route safety
- visual consistency fixes that do not change approved information architecture

Not allowed:
- new modules
- backend/auth/cloud sync
- external APIs
- AI backend
- social/friendship/relationship systems
- major redesigns
- automatic finance mutations from other modules
- broad feature expansion

Stop when the app is ready for live visual/device QA.
